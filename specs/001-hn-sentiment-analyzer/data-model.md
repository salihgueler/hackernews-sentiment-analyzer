# Data Model: HackerNews Daily Intelligence Agent

**Date**: 2026-03-10  
**Feature**: 001-hn-sentiment-analyzer

## Entities

### Story

Represents a HackerNews story with metadata and optional sentiment analysis.

**Fields**:
- `id: number` - HackerNews story ID (unique identifier)
- `title: string` - Story title
- `url?: string` - Story URL (optional, may be missing for Ask HN posts)
- `score: number` - Story score/points
- `by?: string` - Author username (optional)
- `time: number` - Unix timestamp
- `kids?: number[]` - Array of comment IDs (optional, empty if no comments)
- `sentiment?: SentimentResult` - Aggregated sentiment (populated after analysis)

**Validation Rules**:
- `id` must be positive integer
- `title` must be non-empty string
- `score` must be non-negative integer
- `kids` array limited to first 20 items (top-level comments only)

**State Transitions**:
1. Fetched (from API) → has id, title, score, kids
2. Analyzed (after sentiment) → has sentiment field populated
3. Reported (included in final report)

**Source**: HackerNews Firebase API `/v0/item/{id}.json`

---

### Comment

Represents a top-level comment on a HackerNews story.

**Fields**:
- `id: number` - Comment ID
- `text: string` - Comment HTML text content
- `by?: string` - Comment author (optional)
- `parent: number` - Parent story ID

**Validation Rules**:
- `text` must be non-empty (skip deleted/dead comments)
- Only top-level comments (parent is story ID, not another comment)

**Lifecycle**:
- Fetched from API for each story
- Aggregated for sentiment analysis
- Not stored individually in final report

**Source**: HackerNews Firebase API `/v0/item/{id}.json` where id is from story.kids

---

### SentimentResult

Contains aggregated sentiment analysis for all comments on a story.

**Fields**:
- `label: "positive" | "negative" | "neutral" | "No sentiment"` - Sentiment classification
- `confidence: number` - Confidence percentage (0-100), or 0 for "No sentiment"

**Validation Rules**:
- `label` must be one of four allowed values
- `confidence` must be 0-100 inclusive
- If story has zero comments, label is "No sentiment" and confidence is 0

**Relationships**:
- One SentimentResult per Story (1:1)
- Generated by sentiment subagent via LLM analysis

---

### DailyReport

Markdown-formatted report structure (not a runtime object, but a document format).

**Sections**:
1. Header with date
2. Top Stories section (10 stories)
3. Best Stories section (10 stories)

**Per-Story Entry**:
- Story title (linked to URL if present)
- Score
- Sentiment label and confidence (or "No sentiment")

**Output Locations**:
- File: `output/report.md`
- Stdout: Printed to console

---

## Relationships

```
Story (1) ──has──> (0..20) Comment
Story (1) ──has──> (0..1) SentimentResult
DailyReport (1) ──contains──> (20) Story
```

---

## Data Flow

1. **Fetch Phase**: Main agent fetches 20 Story entities (10 top + 10 best)
2. **Comment Phase**: For each Story, fetch up to 20 Comment entities
3. **Analysis Phase**: Sentiment subagent processes Comments → generates SentimentResult per Story
4. **Report Phase**: Summary subagent formats Stories + SentimentResults → DailyReport
